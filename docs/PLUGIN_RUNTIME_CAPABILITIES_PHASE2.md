# Plugin Runtime Capabilities – Phase 2

Phase 2 ergänzt read-only/advisory Verträge:

- `ai.rename_review` – Einzelprüfung
- `ai.rename_batch_review` – Massenprüfung mit Referenz-/Schema-Kontext
- `metadata.read` – Metadaten/NFO lesen
- `metadata.review` – Metadatenänderungen vorschlagen
- `metadata.write` – **nur geplant, nicht registriert, nicht ausführbar**

Alle Phase-2-Verträge sind Vorschau/Review. Dateinamen und Metadaten werden nicht geschrieben.
